Novelle — Writing Diary App

A full-featured CRUD (Create, Read, Update, Delete) diary web application built with a soft lavender academia aesthetic. Novelle lets writers capture their thoughts beautifully — with mood tracking, search functionality, color-coded entries, and persistent local storage. Designed with a feminine, cozy, Pinterest-inspired interface featuring glassmorphism effects, smooth animations, and a fully responsive layout.

✅ Create entries ✅ Read & view entries ✅ Edit & update ✅ Delete with confirmation ✅ Live search ✅ Mood filter (8 moods) ✅ LocalStorage persistence ✅ Fully responsive
Built with HTML5 CSS3 JavaScript LocalStorage API Google Fonts
